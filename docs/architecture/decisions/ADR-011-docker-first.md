# ADR-011 — Docker-first

**Status:** Proposed. Referência canônica temporária: [ADR-011 original](../../saas/ADR-011-DOCKER-FIRST.md).

Decisão: Docker obrigatório para serviços executáveis; Compose como orquestração local inicial; Terraform complementar para provisionamento cloud, sem ser requisito da Sprint 0; Kubernetes fora do escopo inicial.

O texto completo permanece no original até a revisão dos links e da documentação técnica.
